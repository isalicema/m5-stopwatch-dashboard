# M5 StopWatch Dashboard v2026.09.14

首个带预编译 UAC 应用固件的公开 Release，将当前公开分支整理成可下载、可校验、可反馈的版本。
适用于 **M5Stack StopWatch（C152，原厂 16 MB 分区布局）**，配套 Bridge 面向 macOS。

## 下载与安装

- 下载 `M5Dashboard-v2026.09.14-uac.bin` 和 `SHA256SUMS`，校验后按
  [安装指南](https://github.com/isalicema/m5-stopwatch-dashboard/blob/v2026.09.14/docs/install-release.md)
  备份并烧录。
- 附件为应用分区镜像，不是全片镜像。USB 脚本只重置 OTA 选择区并写入 `ota_0`，保留 NVS；
  不要把应用镜像写到 `0x0`，也不要使用全片擦除。
- Bridge 请使用同一 tag 的源码；本地 Stopwatch / Timer 无需安装 Bridge。
- `build-info.json` 记录固件源码提交、构建环境、大小、SHA-256 与验证范围；
  `THIRD-PARTY-NOTICES.txt` 提供随固件分发的许可声明。

## 当前版本包含

- Dashboard 七屏：时钟、TickTick 专注、Codex、Claude Code、Typeless、AI 热点与 Obsidian 幸运笔记。
- 独立 Stopwatch 与离线 Timer，开机可选择程序。
- 48 kHz USB 麦克风与 USB 自动配对；可选 Wi-Fi 和局域网 OTA。
- 最近的交互加固：TickTick 结束状态与双击处理、完成动画判断、USB 串口筛选。
- 仅接充电器时可正常长按关机；电脑识别为 USB 数据设备时保留 Download Mode。
- Typeless helper 按 Mac 原生架构重建。
- 新增问题报告、功能建议与使用体验表单，README 前置下载和最小安装路径。

## 构建与验证

固件和 Bridge 功能源码基于公开提交 `ff855cfe5bc0f8752367b3353850b6d09c9fb9e3`；
本 tag 另外包含安装文档、反馈模板和备份目录忽略规则。构建使用干净的公开源码，
不读取私人配置或旧构建目录，设备凭据保持为空并在首次 USB 配对时写入。

- Dashboard Python：255 项通过。
- Home Bridge Python：23 项通过。
- C++ 交互逻辑测试：通过。
- PlatformIO `m5stack-stopwatch-uac`：通过，ESP32-S3 应用镜像校验通过。
- 字体标记、USB 标识与应用分区容量：通过。

构建命令（在 `m5-dashboard/firmware` 目录执行）：

```bash
PLATFORMIO_BUILD_FLAGS="-ffile-prefix-map=$HOME=/build -ffile-prefix-map=\"$PWD\"=." pio run -e m5stack-stopwatch-uac
```

路径映射避免固件携带构建者的本机用户目录。工具链版本见 `build-info.json`；
本 tag 中的 `platformio.ini` 固定平台及直接依赖版本。

## 验证边界与反馈

**本次发布镜像尚未重新烧录做实机验收。** 编译和自动化测试不证明本次镜像的触控、音频、
续航和实际 TickTick 联动已经验收。固件接近应用分区容量上限，后续增功能需要继续检查镜像大小。
