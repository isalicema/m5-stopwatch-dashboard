# M5 StopWatch Dashboard v1.5.0

这是面向日常使用的稳定发布：本地 Stopwatch、Timer 和 Dashboard 三个程序保持独立，
并把关机、启动与 USB 救援路径收敛为明确且可验证的行为。

## 下载与安装

- 下载 `M5Dashboard-v1.5.0-uac.bin` 与 `SHA256SUMS`，校验后按
  [安装指南](https://github.com/isalicema/m5-stopwatch-dashboard/blob/v1.5.0/docs/install-release.md)
  备份并烧录。
- 附件是应用分区镜像，不是全片镜像。烧录脚本只重置 OTA 选择区并写入 `ota_0`，保留 NVS；
  不要写入 `0x0`，也不要全片擦除。
- Bridge 应使用同一 tag 的源码；本地 Stopwatch 与 Timer 不需要 Mac Bridge。
- 附件包含 `build-info.json`、`SHA256SUMS` 与 `THIRD-PARTY-NOTICES.txt`，分别记录构建、
  完整性校验与随二进制分发的许可说明。

## v1.5.0 包含

- 关机后单击红色电源键开机，并显示 `STARTING`；运行中短按熄屏/唤醒，双击进入三 App 程序选择器。
- 长按先显示完整、可取消的 `SHUTTING DOWN` 进度，按满后才真关机。
- M5PM1 Download Mode 在电池或仅供电时被锁住，避免抢在应用关机前进入黑屏下载状态；
  仅真实 USB 数据主机连接时保留救援入口。
- USB 救援烧录只选择唯一的新枚举端口，不会把仍存在的无关 `usbmodem` 设备当作 StopWatch。
- TickTick 结束态、A/B 双击容错、USB 串口筛选、Codex/Claude 状态降噪和 Typeless 原生架构安装修复。

## 构建与验证

构建使用干净的公开 tag 源码，不读取私人配置、旧构建目录或设备凭据。

- Dashboard Python：256 项通过。
- `tests.test_ui_font`：19 项通过。
- C++ 交互逻辑测试：通过。
- PlatformIO `m5stack-stopwatch-uac`：通过；ESP32-S3 应用镜像通过生成与大小校验。
- 完整关机后拔线、单击显示 `STARTING` 并开机：已在同一源码修复上完成真机验收。

固件接近应用分区容量上限（约 98% Flash）；后续增功能必须继续检查镜像大小。
